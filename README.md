I like working on projects that sit between traditionally separate categories: desktop software with serious data capabilities, developer environments that behave like infrastructure, and AI systems that remain inspectable and under the user’s control.

A lot of my work revolves around a few recurring ideas:

* Local-first software that remains useful without a permanent cloud dependency
* Open formats and portable data instead of application-shaped silos
* Reproducible infrastructure from laptops to microVMs and private clouds
* AI as a system capability, not a chat box attached to an otherwise unchanged product
* Interfaces that hide operational complexity without hiding what the system is doing

Outside the editor

I spend an unreasonable amount of time experimenting with homelab infrastructure, networking, 3D printing, hardware projects, robotics, and tools that begin as “a small weekend project.”

I am also interested in product design, economics, urban systems, and the question of why software with enormous technical capability so often feels worse to use than much simpler tools.

Collaboration

I am especially interested in collaborating on:

* Local-first and offline-capable applications
